## 🛠️ Voxy 及其教程 / Voxy and its tutorial

1. `/chunky center` 确定中心坐标
2. `/chunky radius 空格 （输入你需要的区块数）c` 例：`/chunky radius 64c`
3. `/chunky start` 开始生成区块（**需关闭voxy**）
4. 加载区块（**需启用voxy**） `/voxy import world 你的存档名称` 接下来等待进度条走完

<details>
<summary><b>👉 点击展开英文教程 (Click to expand English)</b></summary>

1. `/chunky center` - set the center coordinates.
2. `/chunky radius (enter the number of chunks you need) c` - Example: `/chunky radius 64c`.
3. `/chunky start` - start generating chunks (requires Voxy to be turned off).
4. Load chunks (requires Voxy to be enabled): `/voxy import world [your save name]`, then wait for the progress bar to finish.
</details>

## ⚠️ 注意事项！/ Notes!

1. **在退出存档时是秒退出的**，因为加入了快速推出模组，所以请退出到主界面时，请等待右上方显示保存成功字样在退出游戏。
2. Iris（光影加载器），我加入了 Complementary Shaders - Reimagined 光影，它支持 voxy 和遥远的地平线（默认不开启此光影），或者你自己找也可以。
3. 在游玩时建议 5 区块运行，核显建议不要开光影，因为 MTR 的模型太耗费显卡了（你不玩 MTR 当我没说）。

<details>
<summary><b>👉 点击展开英文注意事项 (Click to expand English)</b></summary>

1. When exiting a save, it quits instantly because the FastQuit mod has been added. Therefore, when returning to the main menu, please wait until the "Saved" message appears in the upper right corner before exiting the game.
2. Iris (shader loader) - I have included the Complementary Shaders - Reimagined shader pack, which supports Voxy and Distant Horizons (this shader is not enabled by default). Alternatively, you can find your own.
3. During gameplay, 5 chunks is recommended for running. Integrated graphics users are advised not to enable shaders, because MTR's models are too GPU-intensive. (If you don't play MTR, ignore this.)
</details>
